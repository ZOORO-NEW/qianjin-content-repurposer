# 配图设计指南 - 小红书 & 公众号

## 核心原则

配图不是装饰，是内容的第二语言。好的配图能：
- 小红书：封面决定70%的点击率，内页图决定收藏率
- 公众号：首图决定打开率，正文配图决定完读率

---

## 一、小红书配图体系

### 1. 封面图（必出1张）

**尺寸**：1080×1440px（3:4竖版）
**作用**：决定点击率，是整篇笔记最重要的元素

#### 封面图类型库

| 类型 | 适用场景 | 设计要点 |
|------|---------|---------|
| 文字卡封面 | 干货类、清单类 | 大字标题+副标题+背景色块，文字占画面60%以上 |
| 对比型封面 | 前后对比、优劣对比 | 左右/上下分屏对比，中间用分割线或VS |
| 步骤型封面 | 教程类、流程类 | 数字1-2-3-4排列，配简笔画或图标 |
| 清单型封面 | 盘点类、推荐类 | 打勾/打叉列表，突出数量（"5个""7种"） |
| 痛点型封面 | 解决问题类 | 问号开头+痛点文字，引发共鸣 |
| 金句型封面 | 观点类、感悟类 | 一句大字金句+简洁背景，适合截图传播 |

#### 封面图设计规范

```
【封面设计方案】
类型：[文字卡/对比型/步骤型/清单型/痛点型/金句型]
尺寸：1080×1440px（3:4）
主色调：[根据内容主题推荐]
标题文字：[封面上的大字，≤12字]
副标题文字：[封面上的小字，≤20字]
文字位置：[居中/顶部/底部]
背景风格：[纯色/渐变/图片+蒙版/手绘风]
视觉元素：[图标/简笔画/数据可视化/装饰线条]
字体建议：[思源黑体/站酷快乐体/手写体]
AI生成提示词：[可直接用于AI图片生成的英文prompt]
```

#### 封面色调推荐

| 内容类型 | 推荐色调 | 色值参考 |
|---------|---------|---------|
| 干货教程 | 莫兰迪蓝/绿 | #5B9BD5 / #70AD47 |
| 美妆时尚 | 裸粉/奶茶色 | #E8C4B8 / #D4A574 |
| 职场成长 | 深蓝/金色 | #1F3864 / #BF9000 |
| 美食生活 | 暖橙/奶油白 | #ED7D31 / #FFF2CC |
| 健康养生 | 薄荷绿/白色 | #A9D18E / #FFFFFF |
| 科技数码 | 深空蓝/银灰 | #2E5395 / #BFBFBF |
| 情感心理 | 暖紫/淡粉 | #B4A7D6 / #F4CCCC |

### 2. 内页图（必出3-6张）

**尺寸**：1080×1440px（3:4竖版，与封面统一）
**作用**：补充正文信息，提升收藏率

#### 内页图类型库

| 类型 | 适用位置 | 设计要点 |
|------|---------|---------|
| 信息卡 | 正文核心观点处 | 提炼1个观点，大字+简短解释，可独立截图 |
| 步骤卡 | 教程步骤处 | 数字编号+步骤名+一句话说明 |
| 对比卡 | 优劣对比处 | 左右分栏，对比清晰 |
| 金句卡 | 每300字处 | 全屏金句，背景简洁，适合截图收藏 |
| 清单卡 | 总结处 | 打勾列表，全部要点一图概括 |
| 数据卡 | 数据论证处 | 用图表/数字大字呈现关键数据 |

#### 内页图设计规范

```
【内页图方案】
图序：第X张/共X张
类型：[信息卡/步骤卡/对比卡/金句卡/清单卡/数据卡]
尺寸：1080×1440px（3:4）
对应正文位置：[标注插入正文的哪个段落后]
标题文字：[图上的标题，≤10字]
正文文字：[图上的内容文字，≤50字]
主色调：[与封面保持同色系]
视觉元素：[图标/数据图/装饰元素]
AI生成提示词：[英文prompt]
```

### 3. 小红书配图整体风格要求

- **统一性**：封面和内页保持同一色调、同一字体风格
- **可读性**：文字足够大，手机端不放大也能看清
- **可截图性**：每张图独立看也有信息量，适合截图分享
- **品牌感**：可在每张图角落加统一的小logo或账号名水印

## 二、公众号配图体系

### 1. 首图/封面图（必出1张）

**尺寸**：900×383px（2.35:1横版）
**作用**：出现在文章列表和分享卡片中，决定打开率

#### 首图类型库

| 类型 | 适用场景 | 设计要点 |
|------|---------|---------|
| 概念插画型 | 观点类、深度分析类 | 抽象概念可视化，风格统一 |
| 数据冲击型 | 数据驱动类 | 大字数字+简洁背景，制造冲击 |
| 场景叙事型 | 故事类、案例类 | 真实场景感，有代入感 |
| 金句型 | 情感类、感悟类 | 核心金句+艺术化背景 |
| 对比冲突型 | 痛点分析类 | 左右/前后对比，制造冲突感 |
| 极简文字型 | 通用 | 大字标题+留白，高级感 |

#### 首图设计规范

```
【首图设计方案】
类型：[概念插画/数据冲击/场景叙事/金句型/对比冲突/极简文字]
尺寸：900×383px（2.35:1横版）
主色调：[根据内容主题推荐]
标题/文字：[图上文字，≤15字]
文字位置：[居中/左侧/右侧/底部]
风格：[扁平插画/写实/极简/水墨/科技感]
视觉元素：[插画/图标/数据图/几何形状]
AI生成提示词：[英文prompt]
```

### 2. 正文配图（建议每800-1000字1张）

**尺寸**：宽度1080px，高度按内容自适应
**作用**：打断文字疲劳，增强信息传达，提升完读率

#### 正文配图类型库

| 类型 | 插入位置 | 设计要点 |
|------|---------|---------|
| 分节图 | 小标题处 | 节标题+序号+装饰，视觉分隔 |
| 概念图 | 核心观点处 | 将抽象概念可视化（流程图/思维导图/关系图） |
| 数据图 | 数据论证处 | 柱状图/折线图/饼图/对比表格 |
| 金句图 | 金句处 | 全屏金句+背景，适合截图分享 |
| 案例图 | 案例处 | 案例场景插画或截图 |
| 对比图 | 对比分析处 | 左右分栏或前后对比 |
| 总结图 | 文末总结处 | 全文要点一图概括 |

#### 正文配图设计规范

```
【正文配图方案】
图序：第X张/共X张
类型：[分节图/概念图/数据图/金句图/案例图/对比图/总结图]
尺寸：1080px宽，高度自适应
对应正文位置：[标注插入正文的哪个段落后]
标题/文字：[图上的文字内容]
主色调：[与首图保持同色系]
风格：[与首图风格统一]
AI生成提示词：[英文prompt]
```

### 3. 公众号配图整体风格要求

- **品牌统一**：首图和正文配图保持同一视觉风格
- **信息增强**：配图要传递文字之外的信息，不做纯装饰
- **阅读节奏**：每800-1000字一张配图，打断文字疲劳
- **金句可截图**：至少1张金句图，方便读者截图分享到朋友圈

## 三、AI图片生成提示词（Prompt）规范

### Prompt编写原则

1. **英文编写**：AI图片生成工具对英文prompt理解更准确
2. **结构化**：主体 + 风格 + 色调 + 构图 + 细节
3. **指定比例**：明确写出aspect ratio
4. **避免文字**：AI生成的文字通常不精确，文字部分建议后期叠加

### Prompt模板

#### 小红书封面/内页图Prompt模板

```
A clean, minimalist [card/poster/infographic] design for [主题内容],
[主色调] color scheme, [风格描述] style,
featuring [视觉元素描述],
with plenty of white space, modern aesthetic,
vertical 3:4 composition, high quality, flat design
--ar 3:4
```

#### 公众号首图Prompt模板

```
A professional [illustration/banner/cover] design for [主题内容],
[主色调] color palette, [风格描述] style,
featuring [视觉元素描述],
clean layout, modern editorial aesthetic,
wide horizontal composition, high quality
--ar 2.35:1
```

#### 金句卡Prompt模板

```
A minimalist quote card design, [主色调] gradient background,
[装饰元素描述], elegant and clean composition,
plenty of negative space, modern typography aesthetic,
vertical composition for screenshot sharing
--ar 3:4
```

### Prompt示例

**示例1：小红书干货封面**
```
A clean minimalist poster design for content marketing tips,
soft blue and white color scheme, flat illustration style,
featuring simple icons of social media platforms and a fish being divided into parts,
plenty of white space, modern aesthetic,
vertical 3:4 composition, high quality
--ar 3:4
```

**示例2：公众号概念首图**
```
A professional editorial cover illustration for a content strategy article,
deep blue and gold color palette, modern flat illustration style,
featuring a conceptual image of one piece of content splitting into multiple platform versions,
clean layout, sophisticated aesthetic,
wide horizontal composition, high quality
--ar 2.35:1
```

**示例3：金句卡**
```
A minimalist quote card design, warm gradient background from cream to soft orange,
subtle geometric line decorations, elegant and clean composition,
plenty of negative space, modern typography aesthetic,
vertical composition for screenshot sharing
--ar 3:4
```

## 五、配图数量标准

| 平台 | 封面/首图 | 内页/正文配图 | 总数 |
|------|----------|-------------|------|
| 小红书 | 1张（必出） | 3-6张 | 4-7张 |
| 公众号 | 1张（必出） | 每800-1000字1张 | 3-5张 |

### 配图数量决策规则

- **小红书**：内容信息量越大，内页图越多。干货教程类5-6张，观点分享类3-4张
- **公众号**：文章越长配图越多。3000字文章3-4张，4000字以上4-5张
- **金句卡必出**：两个平台都至少保证1张金句卡，用于截图传播
