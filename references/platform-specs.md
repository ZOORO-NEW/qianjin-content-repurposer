# 6平台详细规格

## 一、公众号（WeChat Official Account）

### 基本参数
- 字数：2000-4000字（深度文可5000+）
- 排版：短段落（3-5行/段），大量留白
- 图片：首图1080×432px，正文配图1-3张/千字
- 发布频率：周更2-3篇为佳

### 推荐机制
- 社交分发为主（朋友圈+转发）
- 常读用户优先推送
- 互动率（完读率+分享率+留言率）决定二次推荐
- 星标用户打开率最高，新用户靠标题和摘要转化

### 内容特征
- 读者愿意花5-10分钟深度阅读
- 价值观认同 > 信息获取
- 金句是传播核心（可截图分享的句子）
- 结构：痛点引入 → 核心观点 → 分层论证 → 案例支撑 → 金句收尾

### 源文→公众号的改写策略

源文不一定是公众号文章，不同来源需要不同的改写策略：

| 源文类型 | 改写策略 |
|---------|---------|
| 演讲稿/口播 | 补充书面逻辑链，去掉口语废话和重复，增加数据支撑和案例 |
| 短笔记/碎片 | 扩展论证深度，补充背景信息和上下文 |
| 内部文档/报告 | 去掉专业术语，增加故事性和可读性，补充金句 |
| 新闻/资讯 | 增加观点和解读，不只是复述事实，要有立场 |
| 论文/学术 | 通俗化表达，增加生活化案例，保留核心洞察 |
| 个人随笔 | 增加结构和层次，提炼金句，强化逻辑链 |

### 标题公式
- 数字+痛点：「做了3年自媒体才懂的5个搞钱真相」
- 反常识：「你以为的努力，其实是在浪费时间」
- 身份认同：「30岁以后才明白的10件事」
- 悬念留白：「那个辞职回老家的人，后来怎样了」
- 对比冲突：「月薪3000和月薪3万的人，差的不只是钱」

### 开头策略
- 故事冲突型：用一个真实故事或场景制造冲突感，3句话内让读者知道"这篇值得看完"
- 数据冲击型：用一个出人意料的数据开篇，制造认知冲突
- 反常识型：先给出一个违背直觉的结论，再展开论证
- 痛点共鸣型：直接描述读者正在经历的痛点，建立共情

### 金句设计规则
- 每800字一个可截图传播的金句
- 金句特点：短（≤25字）、有对比、有画面感、能脱离上下文独立传播
- 排版：独立成行或**加粗**，不要埋在段落中间
- 示例：「你写的不是内容，是原材料」「搬运是找死，改写才是活路」

### 排版规范
- 小标题分节：## 一、XXX / ## 二、XXX
- 段落：3-5行/段，段间空行
- 重点：关键数据和金句**加粗**
- 分隔线：大节之间用 --- 分隔
- 表格：对比类信息用表格呈现，比文字更清晰
- 配图：1-3张/千字，首图必须有

### 配图规格
- **首图**：900×383px（2.35:1横版），出现在文章列表和分享卡片
- **正文配图**：宽度1080px，高度按内容自适应
- **配图数量**：每800-1000字1张，3000字文章3-4张，4000字以上4-5张
- **配图类型**：概念插画、数据可视化、金句卡、分节图、对比图、案例图、总结图
- **风格要求**：首图和正文配图保持同一视觉风格，品牌统一
- **金句卡必出**：至少1张金句卡，方便读者截图分享到朋友圈
- **文字叠加**：图上文字≤15字（首图）/ ≤50字（正文图），手机端不放大也能看清

详细配图设计指南见 `image-design-guide.md`

### 致命禁忌
- 标题党无内容支撑——读者被骗一次就取关
- 段落超过8行——手机阅读体验差，直接划走
- 全文无金句——没有可传播的"种子"，分享率归零
- 开头铺垫超过3段——读者没耐心等你进入正题

## 二、小红书（Xiaohongshu/RED）

### 基本参数
- 字数：600-900字（最长1000字）
- 图片：1封面+3-8张内页，封面比例3:4（1080×1440px）
- 排版：emoji分段，大量留白
- 发布时间：12:00-14:00 / 18:00-22:00

### 推荐机制
- 搜索+推荐双引擎
- 收藏率是最核心指标（收藏>点赞>评论>关注）
- 首图决定点击率，标题决定打开率
- 笔记标签决定搜索权重

### 内容特征
- 底层逻辑：有用+想收藏
- 情绪驱动：痛点共鸣 > 知识获取
- 清单式结构最受欢迎
- 说教感是最大禁忌

### 标题公式
- 「做了X年XX才懂的X个真相」
- 「试了X次终于搞明白了！XX原来这么简单」
- 「被问疯了！这个XX方法太绝了」
- 「XX人不会告诉你的X个秘密」
- 「后悔没早点知道的X件事」
- 「XX党狂喜！终于找到XX的正确打开方式」

### 开头句式库
- 「谁懂啊……」
- 「不会只有我不知道吧……」
- 「试了N次才发现……」
- 「姐妹们听我说！！」
- 「这个必须收藏！！看完你会感谢我」

### emoji使用规则
- 每段开头一个emoji（不用重复）
- 用emoji做信息层级标记：📌💡⚠️✅❌
- 金句标注：【】或== ==
- 不要过度使用（每段1-2个，全文≤15个）

### 标签规则
- 3-5个#话题标签
- 1个大词（行业词）+ 2-3个中词（场景词）+ 1个小词（长尾词）
- 示例：#自媒体运营 #内容创作 #小红书运营技巧 #搞钱

### 配图规格
- **封面图**：1080×1440px（3:4竖版），决定70%点击率
- **内页图**：1080×1440px（3:4竖版，与封面统一），3-6张
- **配图总数**：4-7张（1封面+3-6内页）
- **封面类型**：文字卡、对比型、步骤型、清单型、痛点型、金句型
- **内页类型**：信息卡、步骤卡、对比卡、金句卡、清单卡、数据卡
- **风格要求**：封面和内页保持同一色调、同一字体风格
- **可截图性**：每张图独立看也有信息量，适合截图分享
- **文字叠加**：封面大字≤12字+副标题≤20字，内页标题≤10字+内容≤50字
- **色调推荐**：根据内容类型选择（干货→莫兰迪蓝/绿，职场→深蓝/金色，美食→暖橙/奶油白等）

详细配图设计指南见 `image-design-guide.md`

## 三、抖音（Douyin）

### 基本参数
- 时长：60-90秒（口播类黄金时长）
- 字数：约200-350字（口语速度约3-4字/秒）
- 画面：竖屏1080×1920px
- 发布时间：11:00-13:00 / 18:00-22:00 / 周末全天

### 推荐机制
- 前3秒完播率决定生死
- 流量池递进式推荐（200→500→1000→5000→1万→10万→100万）
- 核心指标：完播率 > 点赞率 > 评论率 > 分享率
- 评论区互动影响推荐权重

### 内容特征
- 前3秒是全部：留不住人后面全白搭
- 信息密度极高：每15秒一个信息点
- 口语化：每句话≤15字，不要书面语
- 情绪驱动：反常识/震惊/共鸣/愤怒

### 3秒钩子公式
- 反常识型：「你知道吗？[反常识事实]」
- 数据冲击型：「一个数字吓你一跳：[数据]」
- 身份认同型：「做[身份]的，这条视频你一定要看完」
- 悬念型：「我后悔知道得太晚了——[悬念]」
- 对比型：「同样做XX，有人月入X万，有人颗粒无收」
- 痛点直击型：「是不是每次[场景]都[痛点]？」

### 段落衔接句式
- 「还有一个更狠的」
- 「这事还没完」
- 「但最离谱的是」
- 「你以为这就完了？」
- 「更可怕的是什么？」

### 镜头标注格式
```
【镜头推进】
【停顿2秒】
【画面切B-roll：XX场景】
【字幕弹出：关键词】
【音效：XX】
```

## 四、知乎

### 基本参数
- 字数：1500-2000字（高赞回答平均1800字）
- 排版：Markdown格式，加粗重点
- 发布时间：10:00-12:00 / 20:00-23:00

### 推荐机制
- 搜索权重高（百度收录好）
- 赞同数决定排序
- 盐选内容有额外流量扶持
- 长尾效应强（回答半年后仍能持续获得流量）

### 内容特征
- 认知增量：看完觉得"这东西我之前确实不知道"
- 论证经得起挑刺：知乎读者"审"文章
- 有态度不骑墙：中立等于没观点
- 数据/案例支撑：空谈必被折叠

### 高赞回答结构
1. 第一句直接给结论（不铺垫）
2. 第一段：先结论后展开（"这件事的本质是XX，原因有三"）
3. 正文：分层论证（1. 2. 3.），每观点配数据/案例
4. 反问式过渡（"你可能会问，为什么XX？"）
5. 加粗关键数据和金句
6. 结尾留开放性问题引导讨论

### 知乎禁忌
- 不用emoji
- 不用网络热梗
- 不骑墙（"各有各的好"等于没说）
- 不空谈（没有数据支撑的观点会被踩）
- 不啰嗦（知乎用户时间成本高，废话直接划走）

## 五、B站（Bilibili）

### 基本参数
- 时长：8-12分钟（中视频黄金时长）
- 字数：1500-2500字脚本
- 画面：横屏1920×1080px
- 发布时间：17:00-22:00 / 周末全天

### 推荐机制
- 首页推荐+搜索+分区
- 三连率（点赞+投币+收藏）是核心指标
- 弹幕密度影响推荐权重
- 完播率权重高

### 内容特征
- 信息密度+节奏感：每隔2-3分钟一个认知刺激
- 弹幕互动：用户会在弹幕里补充论据、挑逻辑漏洞
- 故事性：B站用户爱听故事，不爱听说教
- 不能有逻辑硬伤

### 脚本结构
1. 开场白（30秒内）：具体故事/场景/问题开场
2. 主体：每2-3分钟一个信息高潮点
3. 弹幕触发句式：引发互动
4. 中段互动引导
5. 结尾：金句+预告+三连引导

### 信息高潮点类型
- 新数据（让人"卧槽"的数字）
- 反转（之前的认知被颠覆）
- 冷知识（没想到还能这样）
- 翻车案例（有名有姓的真实失败）

### 弹幕触发句式
- 「看到这儿肯定有人要发弹幕说XX了」
- 「我知道你在想什么，但真相是——」
- 「弹幕里告诉我，你遇到过XX吗？」
- 「先别急着杠，听我说完」
- 「我猜弹幕已经有人说XX了」

### 画面标注格式
```
【画面：XX】
【B-roll：XX场景素材】
【字幕弹出：关键词】
【音效：XX】
【画面切换：XX到XX】
```

## 六、视频号（WeChat Channels）

### 基本参数
- 时长：60-90秒
- 字数：250-400字
- 画面：竖屏1080×1920px
- 发布时间：12:00-14:00 / 19:00-22:00

### 推荐机制
- 社交推荐为主（好友点赞/转发 → 推给好友的好友）
- 完播率+点赞率是核心
- 朋友圈分享带来裂变
- 直播预约和短视频联动

### 内容特征
- 受众30-50岁为主
- 要"有道理+有用"，不是"有趣+刺激"
- 节奏比抖音慢30%
- 偏沉稳，不要花哨

### 禁忌
- 反问句轰炸（"难道不是吗？""你想想是不是？"）
- 过度亲昵称呼（"家人们""宝宝们"）
- 花哨特效和快剪辑
- 纯娱乐无干货

### 语气定位
像单位里有经验的前辈在跟你聊天——不端着，也不过分亲昵。有阅历感，有务实感。
