# 转化规则库

## 一、句式映射表

同一句话，在不同平台需要完全不同的表达方式。

### 示例：核心观点"坚持比天赋更重要"

| 平台 | 表达方式 |
|------|---------|
| 公众号 | 天赋决定上限，但坚持决定你能不能摸到那条线。 |
| 小红书 | 【说真的】比天赋更狠的东西，叫"日复一日"💡 |
| 抖音 | 你知道吗？最后赢的，从来不是最聪明的那个人。 |
| 知乎 | 决定长期成就的核心变量不是天赋，而是持续投入的阈值。 |
| B站 | 你以为那些大佬是靠天赋？别天真了——他们只是比你多坚持了三千个小时。 |
| 视频号 | 这事琢磨透了就一句话——能坚持的人，运气不会太差。 |

### 句式转换规则

| 规则 | 公众号 → 小红书 | 公众号 → 抖音 | 公众号 → 知乎 | 公众号 → B站 | 公众号 → 视频号 |
|------|----------------|--------------|--------------|-------------|---------------|
| 长句拆短句 | 1句→2-3句 | 1句→2-3短句 | 保持完整 | 1句→2句口语 | 1句→2句缓节奏 |
| 书面→口语 | 去书面语 | 极度口语化 | 保持书面 | 口语化 | 口语但沉稳 |
| 加emoji | 大量添加 | 不用 | 不用 | 不用 | 不用 |
| 加感叹号 | 适量 | 大量 | 不用 | 适量 | 少量 |
| 金句标注 | 无需 | 结尾金句 | 加粗 | 高潮点金句 | 核心处金句 |

## 二、结构重组规则

### 公众号长文 → 小红书笔记

**原始结构**：痛点引入 → 论点1 → 论据1 → 论点2 → 论据2 → 论点3 → 论据3 → 金句收尾

**重组为**：
```
[痛点开头：谁懂啊...]
💡 论点1：一句话结论
   → 一句话解释

📌 论点2：一句话结论
   → 一句话解释

⚠️ 论点3：一句话结论
   → 一句话解释

==收藏级金句==

[结尾：引导收藏]
#标签
```

### 公众号长文 → 抖音脚本

**原始结构**：痛点引入 → 论点1 → 论据1 → 论点2 → 论据2 → 论点3 → 论据3 → 金句收尾

**重组为**：
```
[0-3秒] 钩子：反常识/震惊/痛点
[5-15秒] 验证：一个数据或案例
[15-30秒] 观点1（≤15秒）
[30-45秒] 观点2（≤15秒）
[45-60秒] 观点3（≤15秒）
[60-75秒] 可操作方法
[75-90秒] 结尾金句
```

### 公众号长文 → 知乎回答

**原始结构**：痛点引入 → 论点1 → 论据1 → 论点2 → 论据2 → 论点3 → 论据3 → 金句收尾

**重组为**：
```
[第一句] 核心结论（不铺垫）

这件事的本质是XX，原因有三：

**1. 论点1**
[数据/案例支撑]

**2. 论点2**
[数据/案例支撑]

你可能会问，为什么XX？这才是关键问题——

**3. 论点3**
[数据/案例支撑]

[结尾] 开放性问题引导讨论
```

### 公众号长文 → B站脚本

**原始结构**：痛点引入 → 论点1 → 论据1 → 论点2 → 论据2 → 论点3 → 论据3 → 金句收尾

**重组为**：
```
[0-30秒] 故事开场：具体场景/案例
  【画面：XX】

[30秒-3分钟] 论点1 + 信息高潮点
  弹幕触发句式
  【B-roll：XX】

[3-6分钟] 论点2 + 信息高潮点
  弹幕互动引导
  【画面切换：XX】

[6-9分钟] 论点3 + 信息高潮点
  【画面：XX】

[9-10分钟] 总结金句 + 下期预告 + 三连引导
```

### 公众号长文 → 视频号文案

**原始结构**：痛点引入 → 论点1 → 论据1 → 论点2 → 论据2 → 论点3 → 论据3 → 金句收尾

**重组为**：
```
[开头] 生活场景引入："前段时间我发现一个现象——"

[核心] 观点1+2+3融合为1-2个核心金句
  "这事琢磨透了其实就一句话——[金句]"

[结尾] 强调实践价值："这事对咱们普通人有什么用——"
```

## 四、标题转化规则

同一个选题，不同平台的标题完全不同。

### 示例选题：AI不会取代你，但会用AI的人会

| 平台 | 标题 |
|------|------|
| 公众号 | AI不会取代你，但会用AI的人会——关于AI焦虑，这是最清醒的回答 |
| 小红书 | 被AI取代焦虑？5个真相让你瞬间清醒💡 |
| 抖音 | 99%的人都搞错了！AI不会取代你，但这件事会 |
| 知乎 | 如何评价"AI不会取代你，但会用AI的人会"这个观点？ |
| B站 | AI到底会不会取代你？我花了3个月调研了100个案例，答案出乎意料 |
| 视频号 | 关于AI焦虑，有个现象你一定得知道—— |

### 标题公式映射

| 公众号公式 | 小红书变体 | 抖音变体 | 知乎变体 | B站变体 | 视频号变体 |
|-----------|-----------|---------|---------|--------|-----------|
| 数字+痛点 | 数字+痛点+emoji | 数字+震惊 | 如何评价XX | 我调研了X个XX | 关于XX有个现象 |
| 反常识 | 反常识+感叹 | 反常识+悬念 | 为什么说XX | XX的真相是什么 | XX其实就一句话 |
| 身份认同 | 身份+秘密 | 身份+必看 | XX群体如何看待 | 作为XX我想说 | 做XX的注意了 |
| 悬念留白 | 悬念+收藏 | 悬念+反转 | XX是怎样的体验 | 我经历了XX | 有个事得说说 |
| 对比冲突 | 对比+选择 | 对比+站队 | A和B哪个更XX | A vs B终极对比 | A和B的区别就一点 |

## 五、信息密度调整规则

### 密度递减排序（从高到低）
1. 抖音（每15秒一个信息点）
2. B站（每2-3分钟一个高潮点）
3. 知乎（每段一个核心论点+数据）
4. 公众号（每300字一个金句）
5. 小红书（每段一个小结论）
6. 视频号（1-2个核心金句即可）

### 信息筛选规则

源文有5个论点时：

| 平台 | 保留论点数 | 策略 |
|------|-----------|------|
| 公众号 | 全部5个 | 完整保留（源平台） |
| 小红书 | 3个 | 选最有用的3个，改为清单式 |
| 抖音 | 2-3个 | 选最反常识的2-3个 |
| 知乎 | 全部5个 | 完整保留但重构论证 |
| B站 | 3-4个 | 选最有故事性的3-4个 |
| 视频号 | 1-2个 | 只留最核心的1-2个金句 |

## 六、万能转化流程

```
源文输入
  ↓
[1. 内容解构]
  - 提取核心观点（3-5条）
  - 提取金句（3-5条）
  - 提取数据素材
  - 提取案例素材
  ↓
[2. 平台筛选]
  - 评估每个平台适配度
  - 标注优先级（必发/选发/不适配）
  ↓
[3. 逐平台转化]
  - 按句式映射表转换表达
  - 按结构重组规则重建框架
  - 按语气矩阵切换风格
  - 按信息密度筛选论点
  - 按标题公式生成3个备选标题
  ↓
[4. 质量自检]
  - 字数/时长检查
  - 语气匹配度检查
  - 结构适配检查
  - 合规检查
  ↓
[5. 输出报告]
  - 5平台完整内容
  - 质量评分表
  - 分发建议
```
